Modern, hızlı ve tamamen offline çalışan masaüstü PDF dönüştürücü.
CustomTkinter tabanlı modern arayüz ile PDF işlemlerini internet bağlantısı olmadan bilgisayarınızda gerçekleştirebilirsiniz.

Artık dosyalarınızı online sitelere yüklemek zorunda değilsiniz.

✨ Özellikler
📄 PDF → Word (.docx)
📝 Word → PDF
📋 PDF → Metin (.txt)
🖼️ PDF → Görsel (.png)
📑 PDF Birleştirme
⚡ Modern ve hızlı arayüz
🔒 Tamamen offline çalışma
🌙 Dark mode UI
📁 Toplu dosya desteği
🚫 İnternet gerektirmez
🖥️ Windows masaüstü uyumlu
Neden Bu Projeyi Yaptım?

✅ Gizlilik ve veri güvenliği

✅ Basit ama modern kullanıcı deneyimi
✅ Hafif ve hızlı çalışan lokal bir araç oluşturmak

📁 Desteklenen Dönüşümler
İşlem	Açıklama
PDF → Word	PDF dosyasını düzenlenebilir Word dosyasına çevirir
Word → PDF	DOCX/DOC dosyalarını PDF'e dönüştürür
PDF → TXT	PDF içindeki tüm metni çıkarır
PDF → PNG	Her sayfayı yüksek kaliteli görsele dönüştürür
PDF Merge	Birden fazla PDF dosyasını birleştirir
🔒 Gizlilik

Bu uygulama:

internet bağlantısı kullanmaz,
dosya yüklemez,
veri toplamaz,
cloud servislerine bağlanmaz.

Tüm işlemler lokal bilgisayar üzerinde gerçekleştirilir.

📌 Notlar
docx2pdf bazı sistemlerde Microsoft Word gerektirebilir.
Büyük PDF dosyalarında işlem süresi artabilir.
Görsel dönüştürme işlemleri yüksek kalite için 2x render kullanır.
